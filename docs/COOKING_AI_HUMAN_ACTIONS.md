## OPTIONAL LATER

**Tên: ASR/OCR tiếng Việt local.** Vì sao: thiếu model/packs thì pipeline báo rõ chỉ phân tích sampled frames. Trang chính thức: [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [Tesseract installation](https://tesseract-ocr.github.io/tessdoc/Installation.html), [language packs](https://github.com/tesseract-ocr/tessdata_fast). Hướng dẫn: (1) cài FFmpeg/ffprobe trên PATH; (2) `backend/.venv/Scripts/python.exe -m pip install -r cooking_ai/requirements-video.txt`; (3) tải một CTranslate2 Whisper model từ nguồn liên kết trong faster-whisper vào thư mục local, không dùng URL làm đường dẫn; (4) đặt `COOKING_AI_ASR_MODEL=C:/.../whisper-model` trong backend/.env; (5) cài Tesseract và vie/eng traineddata, thêm binary vào PATH; (6) khởi động lại backend, chạy preprocess trên video tiếng Việt có quyền. Cần nhập: local model path và PATH/tessdata; không cần API key. Chi phí: phần mềm/model mở miễn phí, dung lượng tải/công chạy local. Xác nhận: `tesseract --list-langs` có vie/eng, timeline có audio/OCR đúng nội dung/timestamp, không còn unavailable warning. Codex tiếp tục: chạy ASR/OCR thật và đánh giá alignment; chưa có kiểm chứng lời nói/video nấu ăn tiếng Việt trong lượt này.
